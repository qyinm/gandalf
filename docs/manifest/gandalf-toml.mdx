# `gandalf.toml` Specification

The `gandalf.toml` manifest file defines your team's standardized AI agent configuration. Place this file at the root of your project repository.

---

## Complete Example

```toml gandalf.toml
version = "1.0"
name = "payment-platform"
description = "Standardized AI agent environment for Payment Engineering"
agents = ["claude-code", "codex"]

# 1. Team MCP Servers (Command-based)
[mcp_servers.postgres-db]
command = "npx"
args = ["-y", "@modelcontextprotocol/server-postgres", "${DATABASE_URL}"]
required_env = ["DATABASE_URL"]
description = "Staging database connector for SQL querying"

# 2. Team MCP Servers (HTTP/SSE Remote)
[mcp_servers.mintlify-docs]
url = "https://mcp.mintlify.com"
description = "Mintlify documentation search and creation MCP server"

# 3. Team Skills
[[skills]]
name = "pr-reviewer"
source = "./.gandalf/skills/pr-reviewer"
description = "Automated PR review and style compliance skill"

# 4. Guardrail Hooks
[hooks.pre-save-lint]
event = "before_save"
command = "./scripts/lint.sh"
description = "Run linter before agent writes file changes"

# 5. Environment Variable Template
[env_template]
DATABASE_URL = "postgres://username:password@localhost:5432/payment_dev"
```

---

## Top-Level Fields

| Field | Type | Required | Description |
|---|---|:---:|---|
| `version` | `string` | **Yes** | Schema version (currently `"1.0"`). |
| `name` | `string` | **Yes** | Project / Team name. |
| `description` | `string` | No | Short description of this agent environment. |
| `agents` | `string[]` | **Yes** | Target agents: `["claude-code", "codex"]`. |
| `mcp_servers` | `table` | No | Map of MCP server configurations. |
| `skills` | `array` | No | List of team skills to distribute. |
| `hooks` | `table` | No | Lifecycle hooks and guardrails. |
| `env_template` | `table` | No | Key-value pairs of required environment variables. |

## `[mcp_servers.<name>]` Configuration

### Stdio Command MCP Server
```toml
[mcp_servers.example]
command = "npx"
args = ["-y", "@company/mcp-server"]
env = { DEBUG = "true" }
required_env = ["API_KEY"]
description = "Example MCP tool"
```

### Remote URL / SSE MCP Server
```toml
[mcp_servers.mintlify]
url = "https://mcp.mintlify.com"
headers = { Authorization = "Bearer ${MINTLIFY_KEY:-}" }
description = "Mintlify Docs MCP"
```

## `[[skills]]` Configuration

Skills are stored in `.gandalf/skills/<skill-name>/` and contain a `SKILL.md` entrypoint.

```toml
[[skills]]
name = "security-auditor"
source = "./.gandalf/skills/security-auditor"
description = "Runs automated static security review on changed files"
```

> **Security Note:** Path confinement strictly prevents directory traversal (`../`). All skill sources must reside within the project boundary.
