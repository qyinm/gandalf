# Smart Merge & Safety Engine

When team members execute `gandalf apply`, Gandalf does not overwrite existing configuration files blindly. Instead, it runs the **Smart Merge Engine**.

---

## 1. Non-Destructive Merging

### Claude Code (`~/.claude/settings.json`)
* **Preserved**: User permissions, dark/light theme, custom plugins, custom status line, and personal MCP servers.
* **Merged**: Team MCP servers declared in `gandalf.toml` are injected into `mcpServers` without touching other keys.

### OpenAI Codex (`~/.codex/config.toml`)
* **Preserved**: Model preferences, trusted project list, and existing personal `[mcp_servers.*]` tables.
* **Merged**: Team MCP servers are appended or updated specifically.

---

## 2. Pre-Apply Safety Snapshots

Before modifying a single byte on your machine, Gandalf captures a **content-backed snapshot**:

```text
🛡️  Pre-apply safety snapshot created: preapply-manifest-20260902-120000
   (To roll back: 'gandalf restore --snapshot preapply-manifest-20260902-120000 --apply')
```

If any tool behaves unexpectedly, roll back to your exact previous state with zero data loss.

---

## 3. Path Confinement

All write operations are strictly confined within the declared `HOME` and `PROJECT` boundaries. Gandalf refuses:
* Symlink traversals
* Parent directory references (`..`)
* Writes outside verified agent configuration paths
