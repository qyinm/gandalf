# `.gandalf` Bundle Format

A `.gandalf` bundle is a portable POSIX tar archive used to export and inspect agent configurations across machines.

---

## Archive Structure

```text
daily.gandalf (POSIX tar)
├── .gandalf/format-version
├── manifest.json
├── checksums.sha256
└── snapshot/
    ├── metadata.json
    ├── evidence.json
    └── files/
```

---

## CLI Usage

<CodeGroup>
```bash Export Bundle
gandalf bundle export --name baseline --out team-setup.gandalf
```

```bash Inspect Bundle
gandalf bundle inspect team-setup.gandalf
```

```bash Verify Integrity
gandalf bundle verify team-setup.gandalf
```

```bash Import (Dry-Run Preview)
gandalf bundle import team-setup.gandalf --dry-run
```
</CodeGroup>
