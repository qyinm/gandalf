# The Trust Contract

Gandalf operates under a strict **Trust Contract** designed for safety, transparency, and reversibility.

---

## Core Invariants

<CardGroup cols={2}>
  <Card title="Read-Only by Default" icon="eye">
    Scan, inspect, and check commands never mutate local configuration files.
  </Card>
  <Card title="Review Every Change" icon="file-signature">
    Every write begins with an explicit change preview before disk mutation.
  </Card>
  <Card title="Zero Secret Management" icon="key">
    Raw secret values are omitted/redacted. Gandalf never stores or manages `.env` secrets.
  </Card>
  <Card title="Path Confinement" icon="shield-halved">
    Writes are strictly confined within declared user home and project directories.
  </Card>
</CardGroup>

---

## Safety Guarantees

1. **No Unexpected Execution**: Gandalf does not execute MCP commands, hook binaries, or scripts during discovery or verification.
2. **Offline-First**: Gandalf operates 100% locally on your machine without requiring network access.
3. **Symlink Refusal**: Gandalf strictly refuses to follow symlinks when writing configuration files to prevent directory escape attacks.
4. **Reversible Mutations**: Mutating operations create a rollback snapshot prior to applying changes.
