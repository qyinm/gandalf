# `gandalf apply`

`gandalf apply` synchronizes your declarative team configuration (`gandalf.toml`) with local Claude Code and Codex setups.

```bash
gandalf apply [flags]
```

---

## Flags

| Flag | Shorthand | Default | Description |
|---|:---:|:---:|---|
| `--dry-run` | | `false` | Preview planned changes without writing to disk. |
| `--yes` | `-y` | `false` | Skip interactive confirmation prompt. |
| `--manifest` | | auto | Path to `gandalf.toml` (defaults to project root). |
| `--json` | | `false` | Emit structured JSON output for automation. |

---

## Example Usage

### Safe Preview (Review Changes)
```bash
gandalf apply --dry-run
```

### Interactive Apply
```bash
gandalf apply
```
Prompts:
```text
Apply these changes to local agent configurations? [y/N]: y
```

### CI / Scripted Apply
```bash
gandalf apply --yes
```
