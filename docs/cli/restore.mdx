# `gandalf restore`

`gandalf restore` compares current state against a saved snapshot, presents a **Review Changes** preview, and restores configurations safely.

```bash
gandalf restore [flags]
```

---

## Flags

| Flag | Default | Description |
|---|:---:|---|
| `--snapshot <name>` | *(Required)* | Name of the snapshot to restore from. |
| `--dry-run` | `false` | Preview restore diff without disk mutation. |
| `--apply` | `false` | Apply the restore plan to disk. |
| `--agent <id>` | | Filter restore to `claude-code` or `codex`. |

---

## Examples

### Preview Rollback
```bash
gandalf restore --snapshot preapply-manifest-20260902-120000 --dry-run
```

### Apply Rollback
```bash
gandalf restore --snapshot preapply-manifest-20260902-120000 --apply
```
