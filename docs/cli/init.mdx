# `gandalf init`

`gandalf init` scaffolds a new `gandalf.toml` and `.gandalf/skills/` directory in the current repository.

```bash
gandalf init [flags]
```

---

## Flags

| Flag | Shorthand | Default | Description |
|---|:---:|:---:|---|
| `--name` | | dir name | Project or team name. |
| `--from-current` | | `false` | Scan current local machine setup to generate initial manifest. |
| `--force` | `-f` | `false` | Overwrite existing `gandalf.toml` if present. |
| `--json` | | `false` | Return JSON response. |

---

## Examples

### Initialize Default Template
```bash
gandalf init --name backend-service
```

### Scaffold From Local Agent Setup
```bash
gandalf init --from-current
```
