# `gandalf snapshot & diff`

Gandalf allows developers to capture point-in-time snapshots of their agent configurations and diff against active state.

---

## Snapshot Commands

### Create Snapshot
```bash
# Save content-backed snapshot
gandalf snapshot create --name baseline-clean --agent claude-code --scope user

# Save metadata-only snapshot
gandalf snapshot create --name metadata-only --metadata-only
```

### List & Show Snapshots
```bash
gandalf snapshot list
gandalf snapshot show baseline-clean
```

---

## Diff Commands

```bash
# Compare saved snapshot with current machine setup
gandalf diff baseline-clean current --agent claude-code --scope user

# Emit JSON diff for tooling
gandalf diff baseline-clean current --json
```
