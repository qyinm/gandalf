# `gandalf check`

`gandalf check` compares the declared team manifest with your current machine setup and reports missing MCP tools, skills, or hooks.

```bash
gandalf check [flags]
```

---

## Flags

| Flag | Shorthand | Default | Description |
|---|:---:|:---:|---|
| `--ci` | | `false` | Return exit code `1` if any drift or errors are detected. |
| `--manifest` | | auto | Path to `gandalf.toml` (defaults to project root). |
| `--json` | | `false` | Output results in structured JSON format. |

---

## CI/CD Pipeline Integration (GitHub Actions)

Add a drift check step to your team's pull request workflow:

```yaml .github/workflows/agent-drift.yml
name: Agent Environment Check

on:
  pull_request:
    paths:
      - 'gandalf.toml'
      - '.gandalf/skills/**'

jobs:
  verify-agent-manifest:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Install Gandalf
        run: curl -fsSL https://raw.githubusercontent.com/qyinm/gandalf/main/install.sh | bash
      - name: Check Manifest Validity
        run: gandalf check --ci
```
