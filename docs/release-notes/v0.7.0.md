# v0.7.0 Release Notes

Release title: `v0.7.0 - Agent Environment as Code & Team Manifest Sync`

## Summary

v0.7.0 introduces **Agent Environment as Code** to Gandalf. Engineering teams can now standardize, verify, and synchronize their AI agent environments (MCP servers, skills, hooks) across Claude Code and OpenAI Codex using a declarative `gandalf.toml` manifest, backed by non-destructive smart merging and automatic safety rollback.

## Highlights

- **`gandalf.toml` Team Manifest**: Declare target agents (`claude-code`, `codex`), command/URL-based MCP servers with `${ENV_VAR}` template interpolation, team skills (`.gandalf/skills/`), and guardrail hooks.
- **`gandalf init`**: Scaffolds a starter `gandalf.toml` and `.gandalf/skills/` directory, with optional `--from-current` scanning of active machine setup.
- **`gandalf check`**: Detects configuration drift between the declared team manifest and local agent environments, with `--ci` exit codes for pull request verification.
- **`gandalf apply`**: Non-destructively merges team tools into `~/.claude/settings.json` and `~/.codex/config.toml` while preserving all developer-specific settings (hooks, plugins, themes, and personal MCP tools).
- **Automatic Pre-Apply Safety Backup**: Creates content-backed rollback snapshots prior to disk writes, enabling instant recovery via `gandalf restore`.
- **Path Confinement Security**: Strictly enforces security boundaries preventing symlink escapes and directory traversal (`..`).
- **Official Documentation Suite**: Integrated Mintlify documentation (`apps/docs/`) and updated landing website (`apps/landing/`) under `usegandalf.com`.
