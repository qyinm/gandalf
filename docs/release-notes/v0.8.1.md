# v0.8.1 Release Notes

Release title: `v0.8.1 - Faster TUI Boot and Import Wizard Polish`

## Summary

v0.8.1 is a patch on the v0.8.0 loop. `gandalf tui` now paints Changes-First Home in tens of milliseconds instead of more than a second, and the import wizard gets a responsive preview, overwrite confirmation, and UI polish.

## Highlights

- **Faster TUI boot**: Home no longer captures current skill file bodies, walks Codex `~/.codex/plugins/cache` as skills, or waits on full snapshot JSON. One scan feeds baseline status; Timeline and Saves load after Home is ready.
- **Measured**: full TUI boot replica on this machine (gandalf repo + real `~/.gandalf`) went from **1.640s to 50ms**.
- **Compatible drift**: older snapshots that still contain plugin-cache skills do not show phantom removals. Installed Codex plugins from `config.toml` still appear as drift.
- **Import wizard polish**: responsive preview pane, overwrite confirmation modal, and tighter TUI layout for `gandalf import`.
