# v0.8.0 Release Notes

Release title: `v0.8.0 - Import Wizard, Cursor, and CI Drift Gate`

## Summary

v0.8.0 closes the Agent Environment as Code loop. Teams can reverse-generate `gandalf.toml` from existing Claude Code, Cursor, and Codex setups, catch project-level drift in GitHub Actions, and treat Cursor as a first-class supported agent alongside Claude Code and Codex.

## Highlights

- **`gandalf import`**: Reverse-engineers native agent configs (`.mcp.json`, `.cursor/mcp.json`, Codex `config.toml`, skill directories) into a canonical `gandalf.toml`, with project-over-global precedence and atomic skill mirroring into `.gandalf/skills/`.
- **Secret templatization**: Detected API keys, tokens, and connection strings are rewritten as `${ENV_VAR}` and declared in `[env_template]` so credentials never land in git-tracked manifests.
- **Interactive import wizard**: On a TTY, `gandalf import` opens a Bubbletea TUI to group sources by agent, toggle servers/skills, preview a masked manifest, and confirm overwrite. `--json`, `--dry-run`, and piped I/O stay headless.
- **Safe CLI modes**: `--project-only`, `--from <path>`, `--dry-run`, `--force`, and `--json` cover automation and CI without writing unexpected files.
- **`gandalf-check` GitHub Action**: Packaged CI drift gate that runs project-level `gandalf check` so pull requests can fail when agent environments diverge from the team manifest.
- **Cursor as a supported surface**: Scan, check, apply, and restore now treat Cursor as a product-visible agent, not a compatibility leftover.
- **Landing & monorepo**: Turborepo + Bun workspaces for the Go CLI, Astro landing site, and Mintlify docs, with an authentic xterm.js manifesto terminal on the site.
