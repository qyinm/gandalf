# CLI Commands Reference

---

## `gandalf init`
Scaffolds a starter `gandalf.toml` and `.gandalf/skills/` directory.

```bash
gandalf init --name my-project
gandalf init --from-current   # Scaffold from active machine setup
```

---

## `gandalf check`
Detects configuration drift between the team manifest and local agent environments.

```bash
gandalf check
gandalf check --ci            # Exit with code 1 on drift for CI pipelines
```

---

## `gandalf apply`
Synchronizes the team manifest with local Claude Code and Codex configurations.

```bash
gandalf apply --dry-run       # Preview Review Changes without disk writes
gandalf apply --yes           # Apply with automatic safety snapshot
```

---

## `gandalf restore`
Rolls back configurations safely from point-in-time snapshots.

```bash
gandalf restore --snapshot <snapshot-name> --dry-run
gandalf restore --snapshot <snapshot-name> --apply
```
